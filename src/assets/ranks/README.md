# Ranked emblems

`iron.png` … `challenger.png` are Riot Games' official ranked crests from the
[Riot Developer Portal](https://developer.riotgames.com/docs/lol) download
"Ranked Emblems Latest" (`static.developer.riotgames.com/docs/lol/ranked-emblems-latest.zip`,
files `Rank=<Tier>.png`), resized from 1000 px to 256 px with transparency kept.

They are Riot Games' property, used under Riot's "Legal Jibber Jabber" policy for
community projects. See the notice in the main README.

The unranked theme has no official emblem. It uses a CSS hextech rune
(`.crest-unranked` in `src/styles/panel.css`) rather than a made-up crest.
